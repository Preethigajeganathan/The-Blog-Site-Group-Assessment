# The-Blog-Site-Group-Assessment

A responsive multi-page blog website created using **HTML5** and **CSS3** as part of a group web development project. The website demonstrates the use of semantic HTML, responsive design, navigation, and teamwork using GitHub and the SCRUM methodology.

---

## 📌 Project Overview

The Blog Site is designed to provide readers with informative articles related to technology and web development. The project was developed by a student team following Agile and SCRUM practices while using GitHub for version control and collaboration.

---

## ✨ Features

- 🏠 Responsive Home page
- 👥 About Us page
- 📞 Contact Us page
- 📌 Sticky navigation bar
- 🖼️ Technology-themed images
- 🎨 Modern and responsive CSS styling
- 📱 Mobile-friendly layout
- 🦶 Footer displayed on every page

## 🚀 How to Run

1. Clone the repository.

```bash

```

2. Open the project folder in Visual Studio Code.

3. Open **index.html** in your preferred web browser.
